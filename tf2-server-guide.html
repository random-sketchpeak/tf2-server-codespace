Setup Steps
01
Step One
Create a GitHub Codespace
Head to GitHub Codespaces and spin up a new cloud workspace. Use the default blank template — no repo needed. GitHub gives you free compute hours every month.
Open Codespaces →
💡 Choose 4-core or higher for smoother server performance. The codespace opens a VS Code editor in your browser — no installs required.
02
Step Two
Open the Terminal
Once the codespace finishes loading, open the integrated terminal. In VS Code, use the menu Terminal → New Terminal, or press the keyboard shortcut below.
⌨ Ctrl + `  (backtick)
💡 On Mac, the shortcut is also Ctrl + ` (not Cmd). You should see a bash shell prompt appear at the bottom of the screen.
03
Step Three
Download the Setup Script
In the terminal, run the following command to download the TF2 server setup script directly from the internet. This fetches a pre-configured shell script that handles everything automatically.
$ wget -O setup.sh https://gist.githubusercontent.com/random-sketchpeak/01460ad613a38d5332b6850cf999dc42/raw/664ead4e0b525ee8d8adfbc829291a91d7d1f44a/setup.sh
⚠ Make sure you get the full URL above — it's long! Using the Copy button avoids typos.
04
Step Four
Make it Executable & Run It
First, give the script permission to execute. Then launch it. The script will automatically download and configure your TF2 dedicated server — this may take a few minutes.
$ chmod +x setup.sh
$ ./setup.sh
🚀 Sit back and let the script do its thing. It'll download SteamCMD and all required TF2 server files. Watch the terminal output for progress — when it's done, your server address will be displayed.
05
Step Five
Launch the Server & Connect
Once setup.sh finishes, it will have created a start.sh file. Run it to fire up your TF2 server — it handles the free port-forward automatically using FakeIP.
$ ./start.sh
FIND YOUR SERVER ADDRESS
Watch the console output scroll by. Look for a line that reads exactly like this — it contains your public server IP and port:
FakeIP allocation succeeded: 169.254.242.140:44112

⚑ Your IP and port will be different from the example above — copy whatever number appears on your screen.

CONNECT IN-GAME
In TF2, open the developer console (press ~) and type the connect command using the IP from the line above:
> connect 169.254.242.140:44112

Replace 169.254.242.140:44112 with your actual FakeIP. Share it with your friends so they can join too!

OPTIONAL — SOURCEMOD & METAMOD

Want admin commands, plugins, and full server control? Re-run setup.sh and select the SourceMod & Metamod install option from the menu. Once installed, run it a second time and paste in your Steam community profile page URL when prompted — this grants you admin access on the server.

$ ./setup.sh
👥 Your friends just need to type connect <your-fakeip> in their TF2 console — no special software needed on their end!
